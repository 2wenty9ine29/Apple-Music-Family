# Music Money v1.69

Clean Apple-style Music Money app with the existing People, Payments, Accounts and payment-history functionality preserved.

## v1.69 changes
- Keeps the clean V1.68 landing page and iPhone Duo photo carousel.
- Restores the original V1.67 app/data logic so the existing people, accounts and payment functionality remain intact.
- Reminders are compact expandable rows: name, last paid, unpaid month(s), and amount are visible first; tap to reveal the full WhatsApp message.
- Ama's reminder combines her payment responsibility internally but the message itself simply ends with the month/months and total amount.
- WhatsApp handoff remains manual: the app prepares the message and opens WhatsApp for contact selection.
